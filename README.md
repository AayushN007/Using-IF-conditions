# Using-IF-conditions

This repository contains basic Python programs that demonstrate how to use `if` conditions in different situations.

## Topics Covered

- Simple `if` statements
- `if-else` statements
- `if-elif-else` statements
- Nested `if` conditions

## Description

Conditional statements are used in Python to make decisions based on different conditions.  
This repository is created to practice and understand the use of `if` conditions in Python programming.

## Files

- `prog01.py` – Example program using basic `if` conditions
- `prog02.py` – Example program using `if-else`
- `prog03.py` – Example program using `if-elif-else`

## Learning Goals

- Understand how decision-making works in Python
- Learn the syntax of `if`, `if-else`, and `if-elif-else`
- Practice writing condition-based programs
- Improve logical thinking in programming

## Example

```python
age = 18

if age >= 18:
    print("Eligible to vote")
else:
    print("Not eligible to vote")
```

## Output

```text
Eligible to vote
```

## Conclusion

This repository is useful for beginners who want to learn and practice conditional statements in Python.
